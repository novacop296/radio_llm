## 3. Experiment Lifecycle State Machine

Phase 1.9 implements a 7-state lifecycle with strict immutability locks:

```
 DRAFT
   │
   ▼
CONFIGURED ──(run_experiment)──> RUNNING ──> COMPLETED
                                                 │
                                                 ▼
                                             VALIDATED
                                                 │
                                                 ▼
                                             PUBLISHED (Immutable Lock Active)
                                                 │
                                                 ▼
                                             ARCHIVED
```

- **DRAFT / CONFIGURED**: Editable research parameters (model, view mode, threshold, random seed, bootstrap sample count).
- **RUNNING**: Benchmark inference active.
- **COMPLETED**: Metrics and empirical bootstrap confidence intervals computed.
- **VALIDATED**: Schema, finite numeric check, and ground-truth isolation verified.
- **PUBLISHED**: Permanently locked against mutation. Any attempted update returns an error.
- **ARCHIVED**: Soft-locked with historical reason and audit trail.

## 4. Deterministic Reproducibility & Fingerprinting

Phase 1.9 computes deterministic SHA-256 digests across 4 orthogonal components to form the **Canonical Experiment Fingerprint**:

$$\text{Canonical Fingerprint} = \text{SHA256}(\text{Dataset FP} \parallel \text{Model FP} \parallel \text{Configuration FP} \parallel \text{Environment FP})$$

### Drift Detection States:
- **`REPRODUCIBLE`**: Live dataset, model, config, and environment hashes match the canonical manifest.
- **`DRIFT_DETECTED`**: One or more underlying hashes have drifted from the registered snapshot.
- **`INCOMPLETE`**: Required resources or metrics are pending execution.
- **`INVALID`**: Schema or integrity violation detected.

## 5. Statistical Methodology & Neutral Research Framing

- **Bootstrap Uncertainty Estimation**: Empirical percentile bootstrap resampling ($N \ge 1000$) with a fixed random seed.
- **Metric Differences**:
  - $\Delta_{\text{abs}} = \text{Metric}_{\text{comp}} - \text{Metric}_{\text{base}}$
  - $\Delta_{\text{rel}} = \frac{\Delta_{\text{abs}}}{|\text{Metric}_{\text{base}}|} \times 100\%$ (safeguarded against zero denominators where $|\text{Metric}_{\text{base}}| < 10^{-7}$).
- **Neutral Language Policy**: Strict avoidance of normative or evaluative terms ("superior", "better", "winner", "inferior"). Descriptions report measured numerical differences.

## 6. Structured Research Report (16 Sections)

1. **Experiment Overview**: ID, name, status, created timestamp, researcher ID, hypothesis.
2. **Research Objective**: Diagnostic question scope and representation evaluation.
3. **Dataset Description**: Name, ID, type, cohort size, view pairing.
4. **Dataset Split**: Training, validation, or isolated external validation split.
5. **Model Configuration**: Architecture, weights digest, target visual layer.
6. **Preprocessing Configuration**: Resolution, normalization scheme, pipeline version.
7. **Evaluation Configuration**: View configuration, metric selection, decision threshold, batch size.
8. **Benchmark Configuration**: Execution mode, deterministic seed, runtime environment.
9. **Statistical Methodology**: Bootstrap resamples, confidence level, zero-division safeguards.
10. **Results**: Macro-average and per-finding performance metrics (AUC, sensitivity, specificity, F1, accuracy).
11. **Confidence Intervals**: 95% empirical bootstrap confidence intervals.
12. **Experiment Comparison**: Quantitative differences ($\Delta_{\text{abs}}, \Delta_{\text{rel}}$).
13. **Reproducibility Information**: Component digests, canonical master fingerprint, reproducibility state.
14. **Provenance**: Complete audit trail stages from creation to report export.
15. **Limitations**: Cohort constraints, visual-only representation, multi-view pairing availability.
16. **Research Prototype Disclaimer**: Explicit statement of non-clinical use.

## 7. REST API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/phase19/dashboard` | Summary statistics and experiment lists |
| `GET` | `/api/phase19/experiments` | List registered experiments with status/dataset filters |
| `POST` | `/api/phase19/experiments` | Create a new experiment definition |
| `GET` | `/api/phase19/experiments/<id>` | Retrieve complete experiment metadata |
| `POST` | `/api/phase19/experiments/<id>/validate` | Validate schema, numerics, and ground-truth isolation |
| `POST` | `/api/phase19/experiments/<id>/run` | Execute benchmark evaluation and calculate statistics |
| `POST` | `/api/phase19/experiments/<id>/finalize` | Transition experiment to `VALIDATED` |
| `POST` | `/api/phase19/experiments/<id>/publish` | Permanently lock experiment as `PUBLISHED` |
| `GET` | `/api/phase19/experiments/<id>/metrics` | Retrieve calculated evaluation metrics |
| `GET` | `/api/phase19/experiments/<id>/statistics` | Retrieve descriptive distributions and bootstrap CIs |
| `GET` | `/api/phase19/experiments/<id>/provenance` | Retrieve audit trail stages |
| `GET` | `/api/phase19/experiments/<id>/reproducibility` | Generate reproducibility manifest and drift inspection |
| `POST` | `/api/phase19/experiments/compare` | Compare two or more experiments side-by-side |
| `GET` | `/api/phase19/reports/<id>` | Generate 16-section structured research report |
| `GET` | `/api/phase19/experiments/<id>/export` | Multi-format table export (`json`, `csv`, `text`, `markdown`) |
